# Third-party components

The Rust application and original rule definitions are MIT licensed. The packaged native scanning engine is a separate, unmodified Semgrep CE component, not relicensed under MIT.

- Semgrep CE Core (distributed as the unmodified native payload of the PyPI wheel `semgrep==1.182.0`): LGPL-2.1; full upstream license is `engine/SEMGREP-LICENSE.txt`. Source and build material: https://github.com/semgrep/semgrep/tree/v1.182.0 ; source archive: https://github.com/semgrep/semgrep/archive/refs/tags/v1.182.0.tar.gz ; original wheel: https://pypi.org/project/semgrep/1.182.0/#files . The bundled `semgrep-core.exe` reports its own version as `1.182.1` from an upstream dirty build; no public v1.182.1 tag exists, so the license and source references above describe the wheel this payload was taken from, not a separate core release. `engine/engine-manifest.json` records both version strings and SHA-256 hashes. Engine payload is replaceable independently; retain its license and upstream source references when sharing.
- Semgrep's native Windows distribution includes DLLs for OpenSSL, curl, GMP, libgcc/libstdc++, libwinpthread, tree-sitter, PCRE2, zlib, zstd, gettext, libiconv, libidn2, nghttp2 and libssh2. Their original licenses apply. The exact payload is the unmodified upstream `semgrep/bin` distribution. Upstream build/dependency notices and source references are retained with the Semgrep source distribution; additional source material: https://github.com/semgrep/semgrep/tree/v1.182.0/OSS and https://github.com/semgrep/semgrep/tree/v1.182.0/third-party .
- Rust dependencies are pinned in `Cargo.lock`; major components include eframe/egui (MIT OR Apache-2.0), rfd (MIT), serde/serde_json (MIT OR Apache-2.0), tree-sitter and tree-sitter-c-sharp (MIT), regex (MIT OR Apache-2.0), encoding_rs (Apache-2.0 OR MIT OR BSD-3-Clause), quick-xml (MIT), walkdir (Unlicense OR MIT), tempfile (MIT OR Apache-2.0), chrono (MIT OR Apache-2.0), clap (MIT OR Apache-2.0), sha2 (MIT OR Apache-2.0), windows-sys (MIT OR Apache-2.0). Their upstream licenses continue to apply.
- Chinese fonts are loaded from the user's existing Windows installation. No Microsoft font files are redistributed.
- OSV.dev is contacted at runtime only when the user enables the optional package lookup; no OSV component is bundled. The request contains NuGet package names and versions only, never source code, and responses are cached locally for 24 hours. Usage is subject to https://osv.dev/ and https://google.github.io/osv.dev/ .

No proprietary Semgrep Pro engine, paid rule bundle, SonarQube license, Java runtime or Dependency-Check vulnerability database is included. Original rule definitions in this project do not copy the Semgrep Registry rule library.
